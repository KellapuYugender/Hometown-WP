# Hometown Web Project

Author : Yugender Kellapu
link : https://hometown04.netlify.app

In this project I have represented my hometown's specialities, such as its traditional cuisine, IT industries, and pharma industries. Even though there are many more things to show about my state, I have selected a few things to showcase that make our place unique.

This is a simple web development project which is fun to make, but it also examines and displays one's HTML and CSS skills.
